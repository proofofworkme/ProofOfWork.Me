# Historical May model archive

These twelve files preserve the exact report, JSON, SVG charts, and PNG
companions that occupied the main model artifact paths before the September
2026 all-product update. The model was generated on 2026-05-13 from its
2026-05-11 baseline; the report also contains its preserved 2026-06-13
operational annotation. Undated current-state language inside the archived
files is historical, not present protocol or deployment authority.

`SHA256SUMS` records their bytes at archival time. The historical generator
`../../../scripts/generate-proofofwork-computer-model.mjs` now writes the seven
deterministic Markdown/JSON/SVG outputs into this directory without changing
their contents. The five original PNGs remain preserved rendering evidence.

The current report is [the all-product model](../../proofofwork-computer-agent-adoption-model.md).
